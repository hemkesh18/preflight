# Content Submission Guide

## Hard Rules
- **NEVER mention "hackathon" or "student" or #Hackathon** anywhere in the article, titles, social posts, hashtags, or video script. Any mention results in disqualification.
- Position the project as a real, production-potential engineering system, not a weekend demo or toy.
- Voice: First-person ("I", "we"), pragmatic software engineer talking to other engineers (Hacker News, Reddit, Dev.to).
- No hype, buzzwords, or marketing fluff.
- All numbers must be derived directly from replay data (`data/results/replay.json`).

## Deliverables Required
1. **Article A & B** (800–1,500 words each): Technical write-ups with code snippets, before/after memory examples, and honest takeaways.
2. **Social Posts** (<800 characters each): LinkedIn/X posts in Andrej Karpathy style with specific takeaways, GitHub link, and hashtags (#AIAgents #AI #Hindsight #AgentMemory #LLM).
3. **Video Script & Thumbnail**: 3-minute video walkthrough script with exact screen cues and 16:9 thumbnail prompt.
4. **Demo Runbook**: 60s and 3min live demo scripts with failure fallback and judge Q&A.
